# Jarvis Preview SideStore source

Add https://raw.githubusercontent.com/R347H4CK3R/GhostAI/jarvis-preview-source/source.json in SideStore to opt into unsigned Jarvis prereleases.

This source is separate from the stable source, but the app intentionally retains the existing Asterion Veyra bundle identity. It may therefore update an existing installation, not install a separate app. Export important chats and notes before updating; keep the existing app installed and use the same signing account. Signed physical-device/SideStore data retention, voice and background behavior are not yet verified. Requires iOS 26+; generative chat additionally requires supported, enabled Apple Intelligence with OS-managed model assets.

The stable source, latest stable release and default branch are unchanged. provenance.json records the exact published preview artifact, verification run and checksum.
